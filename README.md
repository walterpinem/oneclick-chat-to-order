## 🔧 Installation

1. **Prerequisites**: Ensure WooCommerce is installed and activated on your WordPress site
2. **Install Plugin**:
   - Via WordPress Admin: Navigate to Plugins → Add New → Upload Plugin
   - Via FTP: Upload the plugin folder to `/wp-content/plugins/`
3. **Activate**: Activate the plugin through the 'Plugins' menu in WordPress
4. **Initial Setup**: Navigate to Chat to Order → Numbers and add your first WhatsApp number
5. **Configuration**: Configure settings in Chat to Order → Basic tab
6. **Testing**: Test the WhatsApp button on a product page

## ❓ FAQ

### Is OneClick Chat to Order free to use?

Yes! OneClick Chat to Order is completely free to use for unlimited sites. All features are included at no cost.

### Can I use multiple WhatsApp numbers?

Absolutely! You can create unlimited WhatsApp numbers and assign them to different product pages, store sections, categories, or departments. [Learn more](https://johndoe.me/projects/oneclick-chat-to-order-mutiple-numbers-feature/)

### What's new in the Force wa.me URL option?

The Force wa.me URL option ensures consistent WhatsApp link behavior across all devices by overriding mobile/desktop base URL settings and using the https://wa.me/ format for all links.

### Is the plugin GDPR compliant?

Yes! OneClick Chat to Order includes comprehensive GDPR features with built-in notice, checkbox requirement, privacy policy integration, and user consent management.

### Is it compatible with WooCommerce HPOS?

Yes! OneClick Chat to Order fully supports WooCommerce High Performance Order Storage (HPOS) and is compatible with WordPress 6.8.3+, WooCommerce 10.0.4+, and PHP 7.4+.
